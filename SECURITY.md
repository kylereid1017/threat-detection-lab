# Security and disclosure policy

This repository accepts only public-source research and inert synthetic fixtures.

Do not submit:

- employer, customer, or partner data
- confidential or proprietary indicators
- credentials, tokens, or secrets
- live phishing pages, malware, or weaponized payloads
- information obtained from non-public production systems

If you discover a problem in this repository, open a GitHub issue that contains no sensitive data. For a potentially sensitive issue, contact the maintainer privately before disclosing details.
