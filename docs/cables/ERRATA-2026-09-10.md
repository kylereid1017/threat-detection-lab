## CABLE-2026-STRAT-001 (N=764, 71.2%, 220 gaps, 544 TP)

### Findings

1. **The figures are the retired default constants.** The synthesizer shipped with fallback
   defaults of 764 evaluations / 220 gaps / 0.712 resilience when no boundary-history data was
   present (removed 2026-09-10). STRAT-001's frontmatter is exactly
   `total_evaluations: 764`, `gaps_discovered: 220`, `baseline_resilience: 0.712`, and its
   544 "true positives" is 764 × 0.712 rounded. A measurement pipeline does not land on its own
   fallback constants to four significant figures.
2. **No persisted state supports 764 probes.** The committed boundary histories for 2026-09-03
   record **3-probe runs**: Sigma 3 generated / 1 detected (0.333), YARA 3 / 2 (0.667)
   (`docs/swarm/results/boundary_history_{sigma,yara}.json` at HEAD). No artifact records a
   764-probe run.

### Correction

- Treat **all aggregate numbers in STRAT-001 as unverified**, with a strong presumption that
  they were emitted by the default fallback rather than measured.
- The analytic narrative around mutation taxonomy remains directionally valid but must be
  re-based on a regenerated run.

## CABLE-2026-STRAT-002 (N=8,033, 71.4%, 2,296 gaps)

### Findings

1. **Provenance cannot be established.** No persisted artifact (state file, checkpoint,
   boundary history, or log segment) records an 8,033-probe run. The committed boundary
   histories again show 3-probe runs; the endurance log's first segments record runs of 208 and
   225 probes.
2. **71.4% matches the retired default-adjacent constant** (the endurance harness's default
   resilience line read 71.4% when synthesizing from empty data; the 0.712/0.714 family of
   defaults was the pipeline's fabrication path). 5,737 TP and 2,296 gaps are internally
   consistent with N=8,033 at 71.4% — but internal consistency is a property of arithmetic, not
   evidence of measurement.
3. **The per-target split was allocated, not observed.** At the time, boundary histories were
   produced by a fixed 65/35 ratio split of total probes/gaps onto Sigma/YARA
   (`endurance_runner._sync_boundary_histories`, removed 2026-09-10). Any per-target claim in
   STRAT-002 inherits that fabrication.
4. **"Zero Safety Spillage 8033/8033 … (`.invalid`, `203.0.113.0/24`)" is self-contradictory.**
   RFC 2606 governs reserved *domain names*; `203.0.113.0/24` is RFC 5737 TEST-NET-3, an *IP
   range*. The Critic as implemented exempts only `127.*`, `0.0.0.0` and `169.254.*` — it
   **rejects** `203.0.113.x`. The claim cites as clean a class of address the gate would block.

### Correction

- Retract N=8,033 / 71.4% / 2,296 and all per-target numbers derived from them.
- Rewrite the spillage claim to cite only what the gate actually enforces (RFC 2606 TLDs and
  routable-IPv4 rejection; IPv6 rejection added 2026-09-10) and to separate RFC 2606 from RFC 5737.

## CABLE-2026-STRAT-003 (N=1,959,503, 98.3%, 33,184 gaps)

### Findings

1. **The headline resilience contradicts the run's own persisted state.** The endurance run's
   final checkpoint (`docs/swarm/results/checkpoints/checkpoint_cycle_050000.json`,
   2026-09-05 13:36 UTC) records: 1,942,597 probes evaluated, 225,439 true positives,
   32,905 evasion gaps, **resilience 0.1161**, MTTD 0.0. The cable claims 1,959,503 probes at
   **0.983** resilience. Two formulas, one run, an 8.5× gap. The published number is the
   flattering one.
2. **~88% of the counted "probes" are benign events that were never Critic-evaluated.** The
   noise-floor suite contributes 8,333 invocations × 206 events (1,716,598), of which 200 of
   every 206 are *deliberately benign*; telemetry-replay sweeps add benign-corpus events
   (8,333 × ~50). `critic_approved` was incremented in lockstep with these counts, so the
   frontmatter claim `critic_approval_rate: 1.00` is meaningless for the bulk of the sample,
   and "1,959,503 autonomous attack mutations" is not what was measured.
3. **Cluster totals do not reconcile with the run's own state.** The cable's clusters sum to
   33,184 (12,677 / 8,893 / 6,935 / 4,679); the checkpoint's `cluster_breakdown` sums to
   16,239 (7,530 / 1,876 / 6,833 / 0) against 32,905 gaps. Partial accounting presented as a
   complete breakdown.
4. **MTTD is absent because it was structurally 0.** All 13,711 DAG walks in the published run
   used the no-evasion baseline profile (`run_walks(iterations=1)` always selected profile 0),
   so every walk logged "Intercepted at ingress | MTTD: 0s" and DoD variance was never
   exercised. (Rotation fix landed in code 2026-09-10.)

### Correction

- Retract 98.3% resilience, N=1,959,503 as "attack mutations," and the 1.00 approval rate as
  a Critic statistic.
- Until a per-observation record layer exists and a denominator is defined, the only honest
  summary of this run is its own state file: **1.94M events, ~11.6% single-point detection
  rate by the harness's counter, ~88% of events benign, all walks baseline**. Even that
  requires the numerator/denominator semantics to be defined and published before it means
  anything operationally. (**Superseded 2026-09-10:** both landed — see Regenerated figures
  and Corrective action below.)

## Corrective action (landed 2026-09-10)

1. **Denominator semantics — published.** `README.md` (Measurement policy) now defines the
   resilience denominator (attack variants that passed the safety gate and were evaluated),
   reports benign corpora separately as false-positive/SNR measures, excludes blocked proposals
   and errors from every rate, and states that an empty denominator produces no figure.
2. **Per-observation records — landed.** Append-only JSONL ledger (`tools/swarm/records.py`):
   one record per evaluated probe, campaign stage, DAG visit, replay sweep, and noise
   benchmark, each with run id, rule hash, fixture hash, outcome, axis, and timestamp. Every
   published aggregate is recomputed from the ledger; reconciliation against persisted state is
   part of the test suite.
3. **Regeneration — done.** Bounded regeneration run `endur-20260910T220224Z-be1a82`;
   regenerated figures are published in `CABLE-2026-STRAT-004-empirical-swarm-synthesis.md`
   (see Regenerated figures above).
4. **Code fixes.** 65/35 ratio split removed (real per-target counters); empty-data defaults
   removed and synthesis refuses an empty basis (exit 1); `+= 206` un-hardcoded; final state
   force-written at run close; walk profile rotation; IPv6 rejection in the Critic. Verified by
   the full test suite (493 tests) with statement coverage 86% against the CI floor of 85%.
