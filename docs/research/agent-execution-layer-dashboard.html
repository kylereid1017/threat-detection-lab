PHASE 1: UPSTREAM RFC

MCP Telemetry & Capability Specification

Solving the execution layer gap at protocol level

1. Structured Audit Telemetry ('mcp.tool_call')

Standardizes audit logging emitted by agent hosts:
- Duration in ms, exit code, execution timestamp
- Cryptographic SHA-256 digest of input parameters and outputs
- User authorization provenance (prompted vs ambient)

2. Static Capability Manifest ('mcp-manifest.json')

Requires packages to declare explicit privilege boundaries:
- fs_read_roots & fs_write_roots (e.g. project root only)
- net_allowed_hosts (whitelisted egress destinations)
- allow_child_processes: false (prohibits LOLBin spawning)

Path to Standard: Published in docs/upstream/MCP_TELEMETRY_AND_CAPABILITY_SPECIFICATION.md for submission to Model Context Protocol governance.
