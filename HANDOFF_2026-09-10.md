## Pitfalls, with the cost attached

- **`git add -A` on this branch will sweep docs into the PR.** Cost, paid twice: the review doc was
  committed inside commit `ddc8234`, and a later `git rm --cached` was silently undone by the next
  `git add -A`, leaving the tree "clean" while the file stayed tracked. **Verify with
  `git ls-files <path>` before saying a file is tracked or untracked** — `git status` alone will not
  tell you.
- **Turn caps (cost: most of an earlier session).** `agent.max_turns: none` is *ignored* when
  `HERMES_MAX_ITERATIONS` is set: `cli.py` gates the config branch with `is not None`, so `none`
  falls through to the env var — setting it to `none` lowered the cap from 90 to **35**. Use
  `hermes config set agent.max_turns 0` (0 → `sys.maxsize`, and 0 passes the guard). A **running
  session keeps its old cap until `/new`**, so a cap that fires right after the fix means a stale
  agent object, not a wrong config.
- **`.venv` (Python 3.14) only.** System Python 3.11 lacks `yara`/`pySigma`; the resulting import
  errors look like code failures.
- **A leaked logging `FileHandler` holds the temp dir** → `WinError 32` on cleanup. Always use
  `EnduranceRunner` as a context manager (or call `close()`).
- **Fuzzy patching can match inside the helper it just created.** Cost: an orphaned
  `{_cluster_head(cl_a, pct_a)})` and a broken module. Use exact full-line anchors and re-compile.
- **Tests that read the 18 MB OpenSSF corpus need a presence guard** (`@unittest.skipUnless`). The
  corpus is gitignored by design, so CI failed with `AssertionError: 0 != 138` the first time that
  test ever ran there.
- **A guard test must be negation-aware.** A banned-substring check for "captured enterprise" fired
  on the provenance note saying it is *not* captured enterprise traffic.
- **When a config change "doesn't work", look for an environment override before re-reading code.**
  The turn-cap bug above was one; `HERMES_MAX_ITERATIONS` ghosts are a known pattern upstream.
- **git-bash path mangling:** pass native paths to Python as `C:/...` (`/m/...` mangles to `\m\...`).
- **Defender on this machine is aggressive** — never download package payloads; defang cradle
  strings in prose. Binding inherited discipline.
